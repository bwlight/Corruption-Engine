# Code of Conduct  
_For the Corruption Engine Project_

## 1. Purpose
The goal of this project is to maintain a respectful, safe, and productive environment for anyone who interacts with the repository — whether contributing, reporting issues, or discussing ideas.

This project is currently developed primarily by a single author, but this Code of Conduct applies to all future collaborators and community members.

---

## 2. Our Standards

### We commit to:
- Being respectful and considerate in all discussions.
- Welcoming feedback, ideas, and constructive criticism.
- Maintaining a space free of harassment, discrimination, or hostility.
- Keeping communication focused on improving the project.

### Unacceptable behavior includes:
- Harassment, insults, or personal attacks.
- Discriminatory language or conduct.
- Trolling, baiting, or intentionally derailing conversations.
- Sharing malicious code, exploits, or harmful content.
- Spamming issues, pull requests, or discussions.

---

## 3. Responsibilities

The project maintainer (currently the author) is responsible for:
- Clarifying standards of acceptable behavior.
- Addressing inappropriate behavior.
- Taking action when necessary, including warnings or removal of contributions.

---

## 4. Scope

This Code of Conduct applies to:
- GitHub issues
- Pull requests
- Discussions
- Project documentation
- Any public interactions related to the project

---

## 5. Enforcement

Instances of abusive, harassing, or otherwise unacceptable behavior may be reported directly to the project maintainer.

The maintainer will review and respond to issues in a way that is fair, consistent, and respectful.

---

## 6. Attribution

This Code of Conduct is adapted from common open‑source community guidelines and simplified for a small, focused project.
